## 一、主刻度：美联储利率预期

**核心命题**：黄金**不升息** —— 买国债有利息、买股票有分红，黄金放十年还是黄金。
所以**美元 / 美债收益率走高 → 黄金吸引力下降**。

```
封锁海峡 → 油价飙升 → 通胀失控 → 美联储加息预期上升 → 黄金跌
```

- **利率预期（加息/降息概率）是主刻度** —— 它带走黄金的中期走势，常常盖过「避险」逻辑。
- **数据落点（脚本已取）**：`macro.fed_watch`
  - `target_rate` —— 当前目标利率
  - `probabilities.{hike, hold, cut}` —— 加息 / 按兵 / 降息概率（0–1 小数）
  - `next_meeting` —— 下次议息会议
- **读法**：`probabilities.hike` 上行 = 利率预期转鹰 = 对黄金偏空（**机制**，不是指令）；
  反之转鸽 = 偏多。**但**当「信用风险」占主导时该链条会失效（见第三节）。
- **佐证指标**：美债 10Y（`macro.indicators.US10Y`）、目标利率历史（`series.FEDFUNDS_TARGET`）。

## 二、两条能解释金价中期方向的链条

| 链条 | 触发 | 传导 | 对黄金 |
|------|------|------|--------|
| **利率链（主）** | 通胀高企 | 美联储加息预期↑ → 美债收益率↑ | **跌** |
| **信用链（副）** | 主权/纸币信用受疑 | 实际利率转负、央行购金、去美元化 | **涨** |

> 视频给出的实证：北美黄金 ETF 单月流出创纪录（赌加息的钱走了），
> 而实物金条需求大涨（防信用风险的钱留下了）——**同一资产，两拨钱，两个方向。**

## 四、黄金避得了什么、避不了什么（框架结论）

- **能避**：纸币不值钱 / 国家印钱 / 实际利率转负 / 主权信用受疑 → **信用链**。
- **避不了**：
  - **流动性风险**（短期）：市场都缺现金时，黄金可能第一个被卖去救仓 → 流动性冲击下
    会与股票**同跌**，而不是对冲。
  - **利率上升风险**（中期）：若通胀→加息的链条占主导，黄金跟着遭殃
    （历史上的石油危机：油价暴涨先推高金价，随后利率暴力抬升，黄金进入长期熊市）。

## 五、这份框架在报告里怎么用

1. **先定主刻度**：本期 `fed_watch.probabilities` 在升还是在降？
2. **再问副刻度**：信用风险 → 若报告包里没有该数据，**写「无数据」**，不猜。
3. **给机制，不给立场**：说「利率预期转鹰 → 对黄金偏空」是**机制**；
   说「建议减仓」越界了（见子代理护栏 2）。
4. **持仓落地**：把机制绑到具体持仓（GLD 权重、SPY 敞口），但**只陈述状态**。
5. **可证伪**：任何方向判断都走 `<!-- CALL:BEGIN/END -->` 预测块，次日由**脚本**判对错 ——
   框架的价值由**命中率**检验，不由作者自评。
